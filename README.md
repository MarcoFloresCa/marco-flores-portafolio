# Portafolio de Marco Flores

Código fuente del portafolio profesional publicado en:

https://marcoflores.cl

## Requisitos

- Node.js 22.13 o superior
- npm

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abre la dirección local que aparezca en la terminal.

## Archivos principales

- `app/page.tsx`: contenido y estructura del portafolio.
- `app/globals.css`: diseño, colores y versión móvil.
- `app/layout.tsx`: metadatos, idioma y tipografías.
- `public/`: recursos públicos y favicon.

## Compilar

```bash
npm run build
```

## Desplegar en Cloudflare

```bash
npm run deploy
```

El proyecto utiliza React, TypeScript, Tailwind CSS y Vinext.
